cpac_2d Asset Viewer

Views the extracted cpac2d.bin assets from Apollo Justice (DS): background images (w/h header + palette + 8×8 tiles), .nanr sprite animations with their cell banks and tiles, and any raw tile or palette data. Everything runs locally in your browser.

For files that start with a 32-byte palette, set Skip bytes to 32 and Palette source to “this file”.

Formats as decoded here. Images: u16 width, u16 height (bit 15 set = 4bpp), then 16 or 256 BGR555 colours, then 8×8 tiles (4bpp low nibble first); verified pixel-exact against the repo's PNG exports. .nanr: NNS KNBA block (sequences of frame entries, each pointing at a cell index). Cell bank: u16 count, count−1 u16 offsets (in u16 units), then per cell u16 OAM count and 3×u16 OBJ attributes per sprite (NDS layout). Rotation/scaling is ignored.
