Fill the slots below from the archive you last opened: palette (.nclr / .pal4 / .pal8) and graphics (.ncgr / -img.bin) are required; cells (.ncer) and animation (.nanr) are optional. Easiest: in the ROM browser, click a file and press Use as Palette / Graphics / Cells / Animation. Raw .pal/-img.bin files use the “Raw graphics depth” setting.

Durations are in 1/60 s ticks. Pixel shifts come from the animation's per-frame translate data (plus rotation/scale when present); untick “Apply pixel shifts” to compare. Per-OAM rotation/scale is not applied. If sprites look wrong, try another palette bank or graphics file from the same archive.

Archives: AAI 2 uses (offset, size|0x80000000) pair tables; AAI 1's romfile.bin uses a plain u32 offset table. Entries starting with 0x10/0x11 are LZ10/LZ11-decompressed on the fly. Formats are auto-detected, so any container that matches can be opened by double-click.
