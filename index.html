.SEQ / .PIX Animation Viewer

Plays sprite animations stored as a .pix tile sheet (BGR555 palettes + 4bpp 8×8 tiles) and one or more .seq files (frame table + sprite lists). Everything runs locally in your browser.

Load files
Animation

Frame durations are in 1/60 s ticks. A duration of 255 is treated as the end marker (the frame is held, or skipped when looping).

Tile sheet

Format as decoded here — .pix: u32 palette count, N × 16 BGR555 colours (index 0 transparent), then 4bpp 8×8 tiles (low nibble first). .seq: u16 0, u16 frame count, u32 0, then 8-byte entries (u16 offset, u16 duration, u32 0); each frame is u32 count followed by 4-byte sprites (x s8, y s8, first tile u8, attr u8: bits 7-6 size, 5-4 shape, 3-0 reserved). Sprite tiles are read in NDS-style 1D mapping, origin at the canvas centre. Unknown attribute bits are ignored.
